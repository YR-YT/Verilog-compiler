# LogicForge Studio - Web EDA Suite

This ZIP archive contains everything needed to run or deploy the **LogicForge Studio** website.

## 🚀 How to Publish Instantly (No Installation Required)

### Option 1: Netlify Drop (Easiest - 10 Seconds)
1. Go to [app.netlify.com/drop](https://app.netlify.com/drop).
2. Drag and drop this extracted folder (or the ZIP directly).
3. Your website is live immediately with a free HTTPS URL!

### Option 2: Vercel
1. Run `npx vercel` in this directory, or upload this repository to GitHub and import it on [vercel.com](https://vercel.com).
2. The included `vercel.json` will route static files automatically.

### Option 3: GitHub Pages
1. Push this folder to a GitHub repository.
2. In repository **Settings** -> **Pages**, choose the `main` branch and root `/`.
3. Save, and your website is published online!

### Option 4: Local Offline Run
- Double-click `index.html` to open it directly in any browser (Chrome, Edge, Firefox, Safari). It runs 100% offline with zero server requirements.
